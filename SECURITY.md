# Security reporting

AirlockOS is under active development. No supported production release or
Qubes OS security equivalence is claimed. Security fixes target the main branch;
older development snapshots are not supported releases.

## Sensitive reports

Use GitHub's [private vulnerability reporting](https://github.com/airlockos-org/airlockos-machine/security/advisories/new)
when available. Otherwise, arrange a private reporting channel with the
maintainer. Do not post exploit details, credentials, or sensitive machine
information in a public issue. No response-time commitment is currently offered.

Include the source revision, affected component, prerequisites, reproduction,
impact, and whether the result came from nested tests or physical hardware.
Use sanitized logs. Non-sensitive bugs can be reported through the issue tracker.
For vulnerabilities in Qubes, Xen, or another dependency, follow the upstream
project's reporting process as well.
